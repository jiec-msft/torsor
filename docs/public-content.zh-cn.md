# 公开内容策略

> 简体中文（主要版本） | [English](public-content.md)

提交到本仓库的所有内容都是公开内容。

## 允许的来源

- 为 Torsor 创建的原创工作。
- 公开文档和标准。
- 使用兼容许可证的公开依赖。
- 合成的示例、Fixture、截图和测试数据。

## 禁止的内容

- 机密或专有的代码和文档。
- 私有仓库、Issue、Pull Request 或工作流引用。
- 非公开日志、Prompt、截图、录屏和设计材料。
- 客户数据、凭据、Token、Cookie 或 Secret。
- 机器特定的用户名、绝对路径和环境细节。

## 将一个想法移入 Torsor

将需求重写为独立、公开的规格。只包含理解该需求所需的问题、预期行为、约束和公开证据。

不要复制原始私有讨论，也不要保留指向它的链接。

发布变更前，检查完整 Diff、Commit Message、生成文件、工作流输出和 Artifact。
