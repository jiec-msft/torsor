# Public Content Policy

Everything committed to this repository is public.

## Allowed sources

- Original work created for Torsor.
- Public documentation and standards.
- Public dependencies with compatible licenses.
- Synthetic examples, fixtures, screenshots, and test data.

## Prohibited content

- Confidential or proprietary code and documentation.
- Private repository, issue, pull request, or workflow references.
- Non-public logs, prompts, screenshots, recordings, and design artifacts.
- Customer data, credentials, tokens, cookies, or secrets.
- Machine-specific user names, absolute paths, and environment details.

## Moving an idea into Torsor

Rewrite the requirement as a standalone public specification. Include only the problem, intended behavior, constraints, and public evidence needed to understand it.

Do not copy the original private discussion or preserve links back to it.

Before publishing a change, inspect the complete diff, commit messages, generated files, workflow output, and artifacts.
