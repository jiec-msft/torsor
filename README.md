# Torsor

Torsor is an open-source workspace for durable collaboration between people and software agents.

Agents may stop, restart, or move between hosts. The work should continue from durable state.

> Agents change. Work persists.

## Status

Torsor is at an early design and implementation stage. Interfaces and behavior will change as the first working slice is built.
